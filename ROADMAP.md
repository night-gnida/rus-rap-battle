# ROADMAP — «РУССКИЙ РЭП БАТЛ» → Яндекс Игры

Текущая точка остановки: [docs/STATUS.md](docs/STATUS.md)

## Принятые решения
- Это наш проект: исходники получены с одобрения правообладателя.
- Название игры: **«РУССКИЙ РЭП БАТЛ»** (короткое «РЭП БАТЛ»); в консоли Яндекса — «Русский Рэп Батл».
- Цель — мультиплатформа: Яндекс Игры, VK Games, Одноклассники (веб) + Android/iOS через Capacitor. Приоритет магазинов: RuStore и VK Play; Google Play/App Store — backlog.
- С 2026-10-12 ведём ДВЕ версии в РАЗНЫХ репозиториях: **цензурная** — ветка `main` (репо `night-gnida/rus-rap-battle`), только она публикуется где-либо; **нецензурная** — ветка `uncensored` (приватное репо `night-gnida/rus-rap-battle-uncensored`), оригинальная лексика, для себя. Общие фиксы/фичи вносятся в обе версии (cherry-pick), расходятся версии только лексикой.
- Монетизация: interstitial на стыках матчей (кулдаун 3 мин, не раньше 2-го матча сессии), rewarded — позже.
- Сохранения: localStorage (префикс `gvn_`) + облачная синхронизация через SDK Player.

## Этап Y1 — SDK-интеграция ✅ (2026-10-08)
- `yandex.js` — адаптер: динамическая загрузка `/sdk.js`, мок вне Яндекса.
- `LoadingAPI.ready()` при появлении тайтла; `GameplayAPI.start/stop` — старт матча, пауза, конец матча.
- Interstitial в `startMatch` (между матчами).
- Облачные сейвы: `player.getData()` → мерж в localStorage + re-apply живого состояния; `store.set` → `player.setData` (дебаунс 1.5 с, флеш при уходе со страницы).
