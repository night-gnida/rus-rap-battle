# ROADMAP — «РУССКИЙ РЭП БАТЛ» → Яндекс Игры

Текущая точка остановки: [docs/STATUS.md](docs/STATUS.md)

## Принятые решения
- Это наш проект: исходники получены с одобрения правообладателя.
- Название игры: **«РУССКИЙ РЭП БАТЛ»** (короткое «РЭП БАТЛ»); в консоли Яндекса — «Русский Рэп Батл».
- Цель — мультиплатформа: Яндекс Игры, VK Games, Одноклассники (веб) + Android/iOS через Capacitor. Приоритет магазинов: RuStore и VK Play; Google Play/App Store — backlog.
- С 2026-10-12 ведём ДВЕ версии в РАЗНЫХ репозиториях: **цензурная** — ветка `main` (репо `night-gnida/rus-rap-battle`), только она публикуется где-либо; **нецензурная** — ветка `uncensored` (приватное репо `night-gnida/rus-rap-battle-uncensored`), оригинальная лексика, для себя. Общие фиксы/фичи вносятся в обе версии (cherry-pick), расходятся версии только лексикой.
- Монетизация: interstitial на стыках матчей (кулдаун 3 мин, не раньше 2-го матча сессии), rewarded — позже.
- Сохранения: localStorage (префикс `gvn_`) + облачная синхронизация через SDK Player.

## Этап Y1 — SDK-интеграция ✅ (2026-10-08)
- `yandex.js` — адаптер: динамическая загрузка `/sdk.js`, мок вне Яндекса.
- `LoadingAPI.ready()` при появлении тайтла; `GameplayAPI.start/stop` — старт матча, пауза, конец матча.
- Interstitial в `startMatch` (между матчами).
- Облачные сейвы: `player.getData()` → мерж в localStorage + re-apply живого состояния; `store.set` → `player.setData` (дебаунс 1.5 с, флеш при уходе со страницы).

## Этап P — платформы (VK, ОК, Android/iOS)

- [ ] **P1. Platform-адаптер**: нейтральный контракт на базе текущего YNDK (ready, gameplayStart/Stop, maybeInterstitial, rewarded-слот, save/onData, countMatch); yandex.js становится одной из реализаций; детект платформы: Yandex — по загрузке /sdk.js, VK/OK — по хосту, Capacitor — по window.Capacitor, иначе mock. События рекламы yndk-ad-open/close переименовать в plat-ad-*.
- [ ] **P2. VK Games + Одноклассники** (ресёрч 2026-10-12 → docs/platforms-publication.md): создание новых игр в интерфейсе ОК ЗАКРЫТО (apiok.ru/apps/platform) — путь в ОК только через VK Mini App с опцией «Опубликовать в Одноклассниках» (игра появляется в ОК за ~30 минут; реклама VKWebAppShowNativeAds в ОК работает, лидербордов в ОК нет). Отдельный FAPI-адаптер не нужен — P3 слит сюда. Интеграция: VK Bridge/Games SDK (реклама, storage). Требования модерации (dev.vk.ru): RU-язык ✓, режим обучения ✓, отключение звука ✓, реклама не сразу после запуска ✓, нужен канал поддержки (сообщество/email), уникальное название, для iOS — Company Name, модерация 2–7 дней. SDK-лимиты: VK Storage 1000 ключей × 4096 символов (наши 6 gvn_*-ключей помещаются с запасом); VK LeaderBoardBox не сохраняет результат без серверного secure.addAppEvent.
- [ ] **P4. Android/iOS (Capacitor)**: обёртка веб-билда; downloadBlob → нативный шеринг/сохранение, fullscreen/ориентация — нативные плагины (в приложении скрыть #rotate-оверлей), иконки/сплэш/подпись; сборки под RuStore и VK Play. Требования магазинов:
  - **RuStore** (help.rustore.ru): аккаунт разработчика (физлицо/самозанятый/ИП/юрлицо — уточнить при регистрации); APK/AAB с цифровой подписью (уникальный package, versionCode растёт, ≤5 ГБ, AAB подписывается до загрузки); карточка: название ≤30 симв. (уникальное), краткое описание ≤80, полное ≤4000, ≤5 тегов, категория, **маркировки внутриигрового контента** (для игр), ≥3 скриншота на тип устройства, иконка 512×512 (полное заполнение фона), ≥1 контакт (Email/ВК/сайт/МАКС); возраст 0+/6+/12+/16+/18+ по 445-ФЗ (наш таргет 12+); модерация авто + ручная, декларация разрешений и типов данных.
  - **Google Play**: аккаунт $25 с верификацией личности; ⚠️ для РФ-разработчиков биллинг/платные приложения недоступны — только бесплатная публикация, платёжный профиль на практике нужен вне РФ; новые личные аккаунты (после 13.11.2023) — закрытый тест **≥12 тестеров × 14 дней подряд**, затем заявка на production access; рейтинг через IARC-вопросник; актуальный Target API; WebView-обёртка допустима, но политика Minimum Functionality/Spam требует оригинального нативного UX (голый враппер сайта отклоняют); privacy policy + Data safety.
  - **App Store** (backlog): Apple Developer $99/год (оплата из РФ недоступна — зарубежный способ/посредник); Guideline 4.2 Minimum Functionality — голый WebView-враппер отклоняют (нужны нативные элементы/фичи); рейтинг-анкета: мат/насилие тянут к 17+ (наша чистая версия — 12+/16+); реальные персоны рэперов — риски по IP/defamation; App Privacy метки; Company Name.

  Итог: **RuStore/VK Play — без блокеров из РФ; Google Play — только бесплатно + обязательный закрытый тест; App Store — самый дорогой/рискованный канал, в backlog.**
- [ ] Общий модерационный риск на всех платформах: реальные персоны рэперов. По букве правил Яндекса (ресёрч 2026-10-12, docs/platforms-publication.md) 12+ при насилии требует «полностью вымышленных персонажей» и смягчённой лексики — **план Б (анонимизация ростера) фактически обязателен для Яндекса, RuStore (отказ за нарушение прав ИС) и App Store (Guideline 5.2.1)**.
