# РУССКИЙ РЭП НА ВЫЛЕТ — Pixel Fighter

Пиксельный пародийный файтинг на чистом Canvas 2D (без движка, 1280×720): 10 бойцов + секретный босс, 8 арен, режимы аркада / версус / обучение, тач + клавиатура, PWA. Готовится к публикации в Яндекс Играх. Исходники — с одобрения автора (dkdanceblog).

## Запуск локально

```
python -m http.server 8931 --directory .
```
→ http://localhost:8931

Вне хостинга Яндекса `yandex.js` не находит `/sdk.js` и работает в мок-режиме: без рекламы и облачных сейвов, игра полностью играбельна.

## Структура

- `game.js` — вся логика (~5700 строк): `CHARS` (статы/цитаты), `MOVES`/`SPECIALS` (фреймдата startup/active/recovery), экраны-состояния (title→mode→…→fight→end), ИИ-бот, WebAudio + HTML-аудио пулы, отложенная загрузка ассетов.
- `sprites.js` — таблица `SPRITE_META`: позы бойцов и якоря ног.
- `yandex.js` — адаптер Yandex Games SDK: LoadingAPI, GameplayAPI, interstitial, облачные сейвы, гейтинг внешних ссылок.
- `assets/` — спрайты, фоны, эффекты, аудио, шрифты, портреты, UI.
- `ROADMAP.md` — план до публикации; `docs/STATUS.md` — где остановились.

## Правила работы с репо

README / ROADMAP / STATUS обновлять после каждого изменения кода и коммитить. Публикация — только по явной команде.
