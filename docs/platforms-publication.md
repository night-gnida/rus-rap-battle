Проверено по официальной документации: 2026-10-13. Ссылки — на первоисточники; цитаты в кавычках.
Контекст: «РУССКИЙ РЭП БАТЛ» — HTML5-файтинг (Canvas 2D), цель 12+, пародийные образы реальных

## 1. Яндекс Игры

### 1.1 Требования публикации
Источник: [Полный список требований](https://yandex.ru/dev/games/doc/ru/concepts/requirements)

- Встроен SDK Яндекс Игр; `LoadingAPI.ready()` при готовности к игре, `GameplayAPI.start()/stop()` при разметке геймплея (п. 1.19, «Методы SDK» — отдельная страница [requirements/1/19](https://yandex.ru/dev/games/doc/ru/requirements/1/19.md)).
- «При потере фокуса звук из игры останавливается» (п. 1.3, [Звук вне игры](https://yandex.ru/dev/games/doc/ru/requirements/1/3.md)).
- Монетизация обязательна: реклама или инап-покупки (п. 1.12, [Монетизация](https://yandex.ru/dev/games/doc/ru/requirements/1/12.md)).
- Прогресс сохраняется сразу после действия игрока, не теряется при обновлении страницы (п. 1.9).
- Архив: в корне `index.html`, имена файлов без пробелов и кириллицы; до 100 МБ в разархивированном виде (п. 1.21–1.22).
- «В играх запрещен интерактивный искусственный интеллект (ИИ)» — заранее сгенерированные ИИ-материалы допустимы (п. 1.23).
- «Реклама не мешает взаимодействовать с игрой и показывается только в логических паузах» (п. 4.4, [Расположение рекламы](https://yandex.ru/dev/games/doc/ru/requirements/4/4.md)); при interstitial/rewarded звук и геймплей на паузе (п. 4.7).
- Скриншоты: реальный геймплей ≥70% изображения (п. 5.1); название уникально и одинаково во всех материалах (п. 5.1.3).
- Контент (раздел 3): запрещены «реалистичные сцены, изображающие насилие и/или жестокое обращение с животными, детьми или пожилыми людьми», политика/войны/религиозные деятели, нарушение авторских прав; встроить YouTube-видео нельзя (п. 3.9).
- Возрастной рейтинг: пять категорий 0+/6+/12+/16+/18+, «содержание игры соответствует заявленному возрастному рейтингу». Для 12+ — обязательные ограничения насилия: «Персонажи полностью вымышленные», «Графика нереалистична», «Кровь только в условном виде», «Смерть показывается как исчезновение»; лексика: «Всю ненормативную лексику нужно смягчить. Недопустимы ругательства, связанные с сексом» ([Возрастной рейтинг](https://yandex.ru/dev/games/doc/ru/requirements/2/7.md)).
- Прохождение — более 10 минут либо мотивация к перепрохождению (п. 2.9); при рейтинге ниже 30 игру снимают с публикации через 3 недели (п. 2.13); язык определяется через SDK (п. 2.14).

### 1.2 Модерация
Источник: [Модерация](https://yandex.ru/dev/games/doc/ru/concepts/moderation)

- Полная модерация (первая публикация/обновления файлов): «3–5 рабочих дней»; контентная (только промо, A/B иконок): 1–2 рабочих дня. Очередь у аккаунтов без истории «может занимать до нескольких недель».
- До модерации нужен заключённый договор (оферта через Консоль или РСЯ), проверка документов ~3 рабочих дня. Лимит: ≤2 заявок на новые игры одновременно (для аккаунтов без истории — 1).
- Кулдаун после отказа удваивается: 24 ч → 2 → 4 → 8 → 16 дней (максимум 384 ч); сброс — раз в 28 дней.
- Частые отказы: контекстное меню браузера, звук во время рекламы/смены вкладки, нет автоопределения языка, нет Game Ready, несохранение прогресса, JS-ошибки, реклама сразу при запуске.

### 1.3 API
- **Реклама** ([Реклама SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-adv.md)): `ysdk.adv.showFullscreenAdv({onOpen, onClose(wasShown), onError})`; `ysdk.adv.showRewardedVideo({onOpen, onRewarded, onClose, onError})`; стики-баннер — `showBannerAdv()/hideBannerAdv()/getBannerAdvStatus()` (включается в Консоли). «Частота вызова полноэкранного блока рекламы управляется платформой» Яндекс Игр; частота rewarded не ограничена. Антифрод: не вызывать рекламу при активном взаимодействии (пример с `setInterval` приведён как неправильный).
- **Сейвы** ([Данные игрока](https://yandex.ru/dev/games/doc/ru/sdk/sdk-player.md)): `player.setData(data, flush)` — максимум **200 КБ** на игрока, лимит 100 запросов/5 мин; `player.getData(keys)`; численные значения — `setStats/incrementStats/getStats` (10 КБ, 60 запросов/мин). Авторизация: `player.isAuthorized()`, `ysdk.auth.openAuthDialog()`. На iOS при своём домене localStorage может сбрасываться — использовать `ysdk.getStorage()` (safeStorage); при загрузке архивом обёртка ставится автоматически.
- **Лидерборды** ([Лидерборды SDK](https://yandex.ru/dev/games/doc/ru/sdk/sdk-leaderboard.md)): доску создаёт разработчик в Консоли («Техническое название лидерборда», иначе 404). `ysdk.leaderboards.setScore(name, score, extraData?)` — **только для авторизованных**, ≤1 запроса/сек, score ≥ 0; `getPlayerEntry()` (60/5 мин, только авторизованные); `getEntries(name, {quantityTop ≤ 20, quantityAround ≤ 10, includeUser})` (20/5 мин). Перед вызовом — `ysdk.isAvailableMethod('leaderboards.setScore')`.
- **Загрузка/геймплей** ([Загрузка игры и разметка геймплея](https://yandex.ru/dev/games/doc/ru/sdk/sdk-game-events.md)): `ysdk.features.LoadingAPI?.ready()`; `ysdk.features.GameplayAPI?.start()/stop()`.

### 1.4 Ограничения РФ
Отсутствуют (платформа российская). Данные о покупках игрока приходят «только для игроков из РФ» (см. Player).

### 1.5 Риски нашего контента
- 12+: по [правилам рейтинга](https://yandex.ru/dev/games/doc/ru/requirements/2/7.md) персонажи при насилии — «полностью вымышленные»; у нас пародийные бойцы с реальными именами рэперов — прямого запрета «реальные персоны» в требованиях нет, но модератор может трактовать против нас. План Б (анонимизация ростера) сохраняется — см. ROADMAP Y2.
- Цитаты из треков/баттлов — риск по п. «нарушение авторских прав» (раздел 3 требований).

## 2. VK Games (каталог игр VK Mini Apps)

### 2.1 Требования публикации
Источник: [Модерация каталога игр](https://dev.vk.ru/ru/games/catalog/moderation)

- «Основной язык игры — русский»; обязательны обучающий режим с подсказками, возможность отключить звук, «игра работает без ошибок на всех выбранных платформах», качественная графика.
- Канал поддержки: «ссылка на сообщество, страница внутри игры, адрес электронной почты или личная страница автора».
- Название уникально и не копирует каталог; нельзя иметь похожую игру (одобрят только «при существенных различиях»).
- Игровая валюта — только за голоса (VK) или ОКи (ОК).
- Для iOS-каталога — поле Company Name.
- Типичные отказы: не заполнены настройки, «игра не работает (проверьте консоль браузера)», «нарушение правил размещения (например, реклама сразу после запуска)».
- Срок: «Проверка обычно занимает от 2 до 7 рабочих дней»; замечания — в «Чате с модератором», после исправлений заявка подаётся повторно.
- Возрастные категории и отдельные требования к РФ-разработчикам на этой странице не описаны (не удалось проверить в других публичных документах каталога).

### 2.2 API (VK Bridge)
Источник: [VK Bridge — обзор](https://dev.vk.com/ru/bridge/overview). Пакет `@vkontakte/vk-bridge`; после подключения обязательно событие `VKWebAppInit` («информирует платформу ВКонтакте о старте приложения»).

- **Реклама** ([VKWebAppShowNativeAds](https://dev.vk.com/ru/bridge/VKWebAppShowNativeAds)): `bridge.send('VKWebAppShowNativeAds', { ad_format: 'reward' | 'interstitial', use_waterfall? })` → `{ result: true|false }`; события `VKWebAppShowNativeAdsResult` / `VKWebAppShowNativeAdsFailed`. Предзагрузка: `VKWebAppCheckNativeAds`. Баннер: `VKWebAppShowBannerAd` / `VKWebAppHideBannerAd` / `VKWebAppCheckBannerAd`. Совместимость: «ВКонтакте и Одноклассники: Android, iOS, Mobile Web, Web».
- **Сейвы** ([VKWebAppStorageSet](https://dev.vk.com/ru/bridge/VKWebAppStorageSet)): ключ ≤100 символов `[a-zA-Z_\-0-9]`; «сохраняются только первые 4096 символов» значения; не более 1000 ключей на пользователя и 1000 вызовов в час (ошибки `103` и `9` Flood control). Чтение: `VKWebAppStorageGet`, список ключей: `VKWebAppStorageGetKeys`.
- **Лидерборды** ([VKWebAppShowLeaderBoardBox](https://dev.vk.com/ru/bridge/VKWebAppShowLeaderBoardBox)): окно с результатами `{ user_result?, global: 0|1 }`; тип таблицы (очки/уровни/миссии) задаётся в настройках игры; лимиты: уровни 1–15 000, очки 1–10 000 000, миссии 1–2000. Важно: `user_result` «не сохраняется на платформе, для сохранения нужен `secure.addAppEvent`» (серверный вызов). **В Одноклассниках метод не поддерживается.**

### 2.3 Ограничения РФ
Платформа российская — ограничений нет.

### 2.4 Риски нашего контента
Требование «основной язык — русский» выполнено. Возрастные категории в публичном документе каталога не расписаны; правила платформы VK («правила платформы, правила VK Mini Apps и правила размещения рекламы») подключаются по ссылке — при подаче заявки перепроверить на предмет реальных персон.

## 3. Одноклассники

### 3.1 Ключевой факт: напрямую новую игру создать нельзя
Источник: [Платформа приложений ОК](https://apiok.ru/apps/platform) (проверено по тексту страницы 2026-10-13):

> «Создание игр и пользовательских приложений (мини-приложений) больше не поддерживается в интерфейсе Одноклассников. Теперь игры и мини-приложения создаются через VK Mini Apps… Игры и пользовательские приложения, которые уже опубликованы в Одноклассниках, продолжат работать».

Путь для нашей игры: публикуем VK Mini App и включаем показ в ОК. Источник: [VK Mini Apps в ОК](https://apiok.ru/apps/vk):

- «Для публикации приложения VK Mini Apps в Одноклассниках необходимо в Панели управления приложением в ВКонтакте включить опцию “Опубликовать в Одноклассниках” и привязать его к пользователю в ОК, подтвердив с помощью OAuth авторизации свой аккаунт».
- «Приложение появляется на платформе Одноклассников в течении 30 минут», изменения синхронизируются столько же.
- Приложение получает свой уникальный ID (отличный от ВК), секретный ключ тот же; аватар грузится в ВК размером 576×576; «режим разработки» (URL для разработки) в ОК не реализован — для тестов рекомендуют отдельное приложение в ВК.
- VK Bridge в ОК поддерживается (есть «таблица совместимости событий VK Bridge в ОК»); реклама `VKWebAppShowNativeAds` работает в ОК (см. совместимость выше), лидерборды `VKWebAppShowLeaderBoardBox` — нет.

### 3.2 Легаси (для справки, помечено устаревшим)
- [Правила размещения приложений ОК](https://apiok.ru/apps/rules): полная работающая протестированная версия, действия от имени пользователя — только с разрешения, иконки «без теней, закруглений по углам или обводок», модерация через JIRA. Раздел помечен: «Информация в разделе устарела и приведена для справки».
- JS SDK (FAPI): обзор [apiok.ru/dev/sdk](https://apiok.ru/dev/sdk) (JavaScript SDK для iframe-приложений, `/dev/sdk/js`). Для новых игр актуален только путь через VK Mini Apps.

### 3.3 Ограничения РФ / риски контента
Платформа российская — ограничений нет. Контентные требования ОК сейчас применяются к играм из VK Mini Apps; публичного возрастного рейтинг-гайда для ОК найти не удалось (проверить при подаче заявки).

## 4. RuStore

### 4.1 Публикация
Источник: [Публикация приложения](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication)

- Загрузка в [RuStore Консоли](https://console.rustore.ru/sign-in); добавляет приложение роль «Владелец компании».
- APK/AAB: лимит файла **5 ГБ**; первая версия подписана сертификатом, имя пакета уникально; следующие версии — та же подпись/пакет, «номер версии больше предыдущего». AAB: «подписи приложения должны быть добавлены отдельно до загрузки .aab». «Обработанные файлы хранятся 14 дней».
- Карточка: название ≤30 символов (уникальное), краткое описание ≤80, подробное ≤4000, до 5 тегов, категория + возрастное ограничение + **маркировки внутриигрового контента (обязательны для игр)**; скриншоты — «не менее 3» на каждый тип устройств; иконка 512×512 (фон заполнен полностью, без прозрачности); контакты — минимум один из Email / группа ВК / сайт / МАКС; видео — только VK Видео (vk.ru, vk.com, vkvideo.ru).
- Подпись: [apk-signature](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/apk-signature) — «Каждый APK-файл должен быть подписан цифровым сертификатом»; своя подпись допустима; если в Google Play используется App Signing — в RuStore нужна та же подпись, иначе пользователи не смогут обновляться.
- Аккаунт: [developer-account](https://www.rustore.ru/help/developers/developer-account) — «Регистрация бесплатна», вход через VK ID, создаётся бизнес-профиль VK Бизнес. (Типы лиц — физлицо/самозанятый/ИП/юрлицо — на этой странице не расписаны; не удалось проверить первоисточник по типам.)

### 4.2 Модерация
Источник: [Правила модерации и требования](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/requirement-apps)

- «Приложения проходят проверку в течение 72 часов с момента их отправки на модерацию». Этапы: авто-проверка (Kaspersky, MobSF) → модератор (контент/функциональность/метаданные) → спецпроверка при необходимости.
- Причины отклонения: нарушение законодательства РФ, запрещённый контент, «нарушение прав интеллектуальной собственности», ошибки в обработке персональных данных, «низкое качество или неработоспособность», нарушения в рекламе/монетизации. Оговорка: «Модерация имеет право отказать в публикации без детализации причин».
- Санкции: предупреждение → отклонение версии → блокировка приложения → блокировка аккаунта. Апелляция — support@rustore.ru, одна, до 30 дней. По требованию госоргана доступ может быть ограничен «незамедлительно».

### 4.3 Рейтинги и маркировки (важно для нас)
- [Возрастные ограничения](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/age-restrictions): 0+/6+/12+/16+/18+. **12+ = «Умеренное насилие, страшные сцены, непристойный контент»**; 16+ = «Насилие или сексуальный контент»; 18+ = «Высокий уровень насилия… упоминание наркотиков или алкоголя».
- [Маркировки внутриигрового контента](https://www.rustore.ru/help/developers/publishing-and-verifying-apps/app-publication/new-version-app/content-warnings) — 7 штук: Жестокость, Страх, Секс, Сквернословие («Есть бранные слова и выражения, относящиеся к нецензурной брани»), Алкоголь и курение, Наркотики, Внутриигровые транзакции. Для нашей чистой версии ожидаемо: Жестокость (драки) + возможно Внутриигровые транзакции; рейтинг 12+.

### 4.4 Монетизация / ограничения РФ
- [Монетизация](https://www.rustore.ru/help/developers/monetization): «Продажа приложения на витрине», «Оформление подписок», «Добавление потребляемых и непотребляемых товаров» — платежи РФ доступны (платформа российская). Есть разделы «Монетизация для юрлиц» и «для нерезидентов».
- Собственного SDK рекламы/сейвов/лидербордов для HTML5-игры в help не описано (для Android-билда монетизация — своя, например Яндекс Ads SDK/AdMob; реклама на витрине — [продвижение](https://www.rustore.ru/help/developers/advertising-and-promotion)).

### 4.5 Риски контента
«Нарушение прав интеллектуальной собственности» — явная причина отказа: пародийные образы реальных рэперов здесь рискованнее, чем на веб-площадках (объект — установленное приложение). План Б (анонимизация) для RuStore актуален.

## 5. VK Play

- Портал разработчика: [developers.vkplay.ru](https://developers.vkplay.ru/) — «Кабинет разработчика | VK Play»; работа с играми (загрузка сборок, модерация, витрина) — внутри кабинета за логином.
- Публикация доступна физлицам: [новость VK Play](https://vkplay.ru/media/news/fizicheskie-lica-teper-mogut-publikovat-igry-na-vk-play) — «Теперь публиковать игры на VK Play могут и физические лица», «Комиссия сервиса составляет всего лишь 5%».
- Целевые платформы сборок: Windows/Android (macOS — через VK Play Cloud; поддержка облака: [support.vkplay.ru/vkp_cloud](https://support.vkplay.ru/vkp_cloud/faq/3742) — «Windows 7/10/11, macOS, Android»).
- Детальные публичные требования к сборкам, карточке и модерации **не удалось проверить**: страницы vkplay.ru — SPA без статического контента, разделы документации за логином кабинета. Проверить внутри кабинета при подаче.

Риски контента: публичных контентных правил не найдено — по опыту площадки (игровой магазин 18+/16+ сегментов) пародийные персоны менее чувствительны, чем в RuStore, но подтвердить нечем.

## 6. Google Play

### 6.1 Регистрация и тестирование
- Регистрация: **$25 однократно**, карты MasterCard/Visa/AmEx/Discover; 18+; верификация личности (может потребоваться «копия удостоверения личности» и карта на своё имя) ([Get started with Play Console](https://support.google.com/googleplay/android-developer/answer/6112435)).
- **Обязательный закрытый тест** для личных аккаунтов, созданных после 13.11.2023: «a minimum of 12 testers who have been opted in continuously for at least 14 days» — минимум 12 тестеров, непрерывно ≥14 дней; затем «Apply for production» на Dashboard и анкета; проверка Google «обычно до 7 дней, иногда дольше» ([App testing requirements](https://support.google.com/googleplay/android-developer/answer/14151465)).

### 6.2 Контент и политика
- **Возрастной рейтинг IARC** ([Content ratings](https://support.google.com/googleplay/android-developer/answer/188189)): анкета обязательна для всех приложений; рейтинги присваивают ESRB/PEGI/USK/ClassInd/GRAC/IARC Generic. Для 12+ (IARC Generic): «насилие над фэнтезийными персонажами или неграфичное над человекоподобными; лёгкая лексика… без грубых ругательств». Реклама в приложении должна соответствовать рейтингу. «Неверные сведения… may result in its removal or suspension».
- **Target API**: с 31.08.2025 новые приложения и обновления — API 35 (Android 15)+; с 31.08.2026 — API 36; существующие приложения с 31.08.2026 — API 35+, иначе «перестанет быть доступным для обнаружения» ([Target API requirements](https://support.google.com/googleplay/android-developer/answer/11926878)).
- **Minimum Functionality** ([Функциональность, контент и UX](https://support.google.com/googleplay/android-developer/answer/9898783)): «Приложения должны работать стабильно, обладать необходимым функционалом и предоставлять содержательный контент»; запрещены «бесполезные мобильные приложения, приложения, которые не содержат интересного контента…». App Store-аналог про «repackaged website» здесь не процитирован — но спам-правила ниже покрывают дубликаты.
- **Спам** ([Спам](https://support.google.com/googleplay/android-developer/answer/9899034)): «Запрещено публиковать приложения, которые полностью повторяют другие приложения»; «Каждое приложение должно предоставлять уникальный контент или услугу».
- **Data safety** ([Data safety](https://support.google.com/googleplay/android-developer/answer/10787469)): обязательна для всех, «даже если данных не собирается — форму заполнить нужно» + обязательная privacy policy. «You alone are responsible for making complete and accurate declarations».

### 6.3 Ограничения РФ
Источник: [Changes to Google Play's billing system for users in Russia and Belarus](https://support.google.com/googleplay/android-developer/answer/11950272):

- С 10.03.2022 «users cannot purchase apps and games, make subscription payments or conduct any in-app purchases of digital goods» в РФ — платные приложения/подписки/инапы для пользователей из РФ не работают.
- С 02.08.2022 требования Payments policy не применяются к платежам пользователей в РФ (т.е. альтернативные оплаты формально не запрещены именно для РФ-платежей).
- В РФ заблокировано скачивание платных приложений; бесплатные доступны.
- Итог для нас: публиковаться может только **бесплатная** версия без Google-биллинга; монетизация — через чужие ad-SDK (Яндекс Ads/AdMob — с оговорками по санкционным ограничениям AdMob для РФ-трафика, отдельно проверять).

### 6.4 Риски контента
IARC-анкета про реальные персоны напрямую не спрашивает; риски — «defamatory content» и IP-претензии (права на имена/образы). WebView-обёртка допустима технически (Capacitor), но приложение должно быть полноценным (у нас — полноценная игра, не враппер сайта).

## 7. App Store (backlog)

### 7.1 Guidelines — ключевые пункты
Источник: [App Review Guidelines](https://developer.apple.com/app-store/review/guidelines/)

- **1.1**: «Apps should not include content that is offensive, insensitive, upsetting, intended to disgust, in exceptionally poor taste, or just plain creepy»; **1.1.1** запрещает «Defamatory, discriminatory, or mean-spirited content… particularly if the app is likely to humiliate… a targeted individual» (профессиональные сатирики — исключение, к нам не относится).
- **1.2 (UGC)**: если в приложении есть пользовательский контент — обязательны фильтрация, механизм жалоб, блокировка пользователей, опубликованные контакты; приложения, использующиеся для «objectification of real people», удаляют. Для нашей игры (нет UGC) — почти не применимо, но шеринга карточек не UGC.
- **4.2 Minimum Functionality**: «Your app should include features, content, and UI that elevate it beyond a repackaged website. If your app is not particularly useful, unique, or "app-like," it doesn't belong on the App Store».
- **5.2.1**: «Don't use protected third-party material such as trademarks, copyrighted works, or patented ideas in your app without permission… Apps should be submitted by the person or legal entity that owns or has licensed the intellectual property». Для пародийных образов реальных рэперов — самый острый пункт.

### 7.2 Регистрация и рейтинги
- [Enrollment](https://developer.apple.com/support/enrollment/): «The Apple Developer Program annual fee is 99 USD»; физлицам — личное имя как продавец, организациям — D-U-N-S и юрлицо. Оплата картой; «If Apple Developer products are unavailable in your region's Apple Store Online» — форма оплаты в USD (доступность для РФ напрямую не расписана; исходное заявление Apple о приостановке продаж в РФ — страница в Newsroom при проверке 2026-10-13 отдаёт 404 — **не удалось проверить по первоисточнику**).
- [Возрастной рейтинг](https://developer.apple.com/help/app-store-connect/manage-app-information/set-an-app-age-rating): обязательное свойство; «An Unrated app can't be published on the App Store». Анкета частотности контент-дескрипторов; категории 4+/9+/12+/17+/18+; есть override на более высокий рейтинг. Драки/конфликтная лексика чистой версии рассчитаны на 12+/16+ (точные пороги — в анкете при заполнении).

### 7.3 Ограничения РФ / риски
Оплата $99 из РФ — практический блокер (зарубежная карта/посредник); выплаты — тоже. Плюс риски 5.2.1/1.1 по реальным персонам. Обоснованно держать в backlog (см. ROADMAP P4).

## 8. Capacitor (обёртка веб-билда)

Источники — официальный репозиторий [ionic-team/capacitor](https://github.com/ionic-team/capacitor) и репозитории плагинов (сам сайт capacitorjs.com из нашей сети недоступен — Cloudflare 403, поэтому цитаты из GitHub-первоисточников тех же доков).

- Подключение к существующему веб-приложению ([README → Getting Started](https://github.com/ionic-team/capacitor#readme)): «Capacitor was designed to drop-in to any existing modern web app»:
  ```bash
  npm install @capacitor/core @capacitor/cli
  npx cap init        # webDir → папка веб-билда
  npm install @capacitor/android && npx cap add android
  npm install @capacitor/ios && npx cap add ios
  npx cap sync        # после каждого обновления веб-билда
  ```
  «Capacitor provides first-class Progressive Web App support so you can write one app and deploy it to the app stores _and_ the mobile web».
- Плагины (официальные README):
  - **Share** — `Share.canShare()`, `Share.share({ title, text, url, dialogTitle })` ([README](https://github.com/ionic-team/capacitor-plugins/blob/main/share/README.md)) — для шеринга карточки боя.
  - **Filesystem** — `Filesystem.writeFile/readFile`, `Directory.*`; теперь отдельный репо [ionic-team/capacitor-filesystem](https://github.com/ionic-team/capacitor-filesystem) ([README](https://github.com/ionic-team/capacitor-filesystem/blob/main/README.md)); на iOS требует Privacy Manifest. Для downloadBlob → сохранение файла.
  - **Screen Orientation** — `ScreenOrientation.lock('landscape')`, `unlock()`, событие `screenOrientationChange` ([README](https://github.com/ionic-team/capacitor-plugins/blob/main/screen-orientation/README.md)).
  - **Splash Screen** — `npm install @capacitor/splash-screen`, `SplashScreen.show()/hide()` ([README](https://github.com/ionic-team/capacitor-plugins/blob/main/splash-screen/README.md)).
  - **Status Bar** — `npm install @capacitor/status-bar`, `StatusBar.hide()` для fullscreen ([README](https://github.com/ionic-team/capacitor-plugins/blob/main/status-bar/README.md)).
- Сборка/подпись: стандартный Gradle/Xcode поверх `npx cap add`; детали в [capacitorjs.com/docs/android](https://capacitorjs.com/docs/android) и [/docs/ios](https://capacitorjs.com/docs/ios) (страницы из нашей сети недоступны — **не удалось проверить содержимое**, но процесс = обычная Android/iOS-сборка).

Замечание для адаптера (P1): в Capacitor-билде SDK Яндекс.Игр не грузится — `window.Capacitor` детект, мок-реализация; реклама в магазинах — через отдельные ad-SDK (Яндекс Ads Mediation/AdMob для Android), это вне текущего объёма.

4. Перед подачей заявок перепроверить: VK Play (в кабинете), возрастные правила каталога VK, доступность Apple Developer для РФ.
